# TrendScout: тренди YouTube і TikTok → ідеї для відео

Інструмент збирає те, що зараз набирає перегляди, і показує, які відео зняти, щоб піти за трендом.

## Запуск на Mac (найпростіше)

1. Завантажте репозиторій: на GitHub натисніть **Code → Download ZIP** і розпакуйте архів. Або в Терміналі:
   ```bash
   git clone https://github.com/vitalikmelnik20-spec/-.git trendscout && cd trendscout
   git checkout claude/lviv-shorts-video-lbistg
   ```
2. Відкрийте теку `trends` і двічі клацніть **`TrendScout.command`**.
   - Якщо macOS пише, що файл «від невідомого розробника», клацніть на ньому **правою кнопкою → Відкрити → Відкрити**. Це потрібно лише один раз.
   - Якщо після ZIP файл не запускається, виконайте в Терміналі: `chmod +x trends/TrendScout.command`.
3. Перший запуск сам підготує Python і попросить ключі: YouTube, OpenAI (ChatGPT), Threads, Claude і бота Telegram. Будь-який можна пропустити клавішею Enter. Для ідей зі сценаріями достатньо одного з двох: OpenAI або Claude. Ключі зберігаються у `~/.trendscout`.
4. Коли все збереться, у браузері відкриється звіт по трьох ринках.

Python 3.9+ зазвичай уже є на Mac. Якщо ні, скрипт підкаже, як його встановити.

З Термінала можна передати опції: `./trends/TrendScout.command --market de` або `./trends/TrendScout.command --demo`.

Інструмент налаштований на три ринки (`trends/markets.json`):

| Ключ | Ринок | Країни | Нішеві фрази за замовчуванням |
|---|---|---|---|
| `ua` | 🇺🇦 Україномовний | UA | вартість життя, ціни |
| `de` | 🇩🇪 Німецькомовний | DE + AT + CH | Lebenshaltungskosten, Preise |
| `us` | 🇺🇸 Англомовний (США) | US | cost of living, prices |

```bash
# 1. Подивитися приклад звіту без ключів та інтернету
python3 trends/trendscout.py --demo

# 2. Справжній запуск: усі три ринки
export YOUTUBE_API_KEY=...            # див. нижче, як отримати
python3 trends/trendscout.py

# Лише один ринок або свої фрази
python3 trends/trendscout.py --market de
python3 trends/trendscout.py --market us --niche "rent prices" --niche "grocery haul"

# 3. Те саме + повні ідеї зі сценаріями від ChatGPT або Claude (назви й хуки мовою ринку, пояснення українською)
pip install openai                    # або: pip install anthropic
export OPENAI_API_KEY=...             # або: export ANTHROPIC_API_KEY=...
python3 trends/trendscout.py --ai --about "Shorts про ціни та життя в різних містах"
```

Відкрийте `trends/out/index.html`. Це загальна сторінка з трьома ринками поруч і двома блоками:

- **Тренд у кількох ринках**: хештеги й слова, які є одразу в кількох ринках. Ці теми найбезпечніше знімати на всі канали.
- **Уже в США, ще не у вас**: хештеги з TikTok США, яких ще немає в топі UA чи DE. Американські тренди часто доходять до Європи за 1–3 тижні, тож можна зняти першим.

З неї є посилання на повний звіт кожного ринку (`latest_ua.html`, `latest_de.html`, `latest_us.html`). Поруч лежать JSON з усіма даними і історія запусків.

Щоб змінити нішеві фрази чи країни назавжди, відредагуйте `trends/markets.json`.

## Що він робить

| Джерело | Що бере | Ключ |
|---|---|---|
| YouTube Data API v3 | Вкладка «Популярне» країни (до 50 відео) і найпопулярніші відео вашої ніші за останні N днів, з підписниками каналів | `YOUTUBE_API_KEY`, безкоштовно |
| Google Trends | Що люди в країні шукають сьогодні, з обсягом пошуків і новинами | не потрібен |
| TikTok Creative Center | Топ хештегів і трендових звуків країни, з позицією і ростом | не потрібен |
| Threads (необов'язково) | Пости за вашими нішевими фразами й ключовими словами тижня: про що пишуть і скільки постів за 48 год | `THREADS_ACCESS_TOKEN`, див. нижче |
| ChatGPT або Claude (необов'язково, `--ai`) | Аналізує всі джерела, групує тренди в кластери і дає **по 3 відео на кожен кластер**: назва, хук на перші 2 секунди, біти сценарію, хештеги, звук, «чому зараз» | `OPENAI_API_KEY` або `ANTHROPIC_API_KEY` |

Для кожного відео рахуються:

- **швидкість**: перегляди за годину від публікації. Це головний сигнал тренду, а не загальні перегляди;
- **залучення**: (лайки + коментарі) / перегляди;
- **×підп.**: перегляди / підписники каналу. Якщо маленький канал набрав у 10 разів більше за свою аудиторію, спрацювала **тема**, а не канал. Такі теми найкраще повторювати («Аномалії» у звіті);
- **бал 0–100**: усе разом.

**Кластери трендів.** Сигнали з усіх джерел (відео YouTube, запити Google, хештеги TikTok, пости Threads) групуються в теми. Для кожної теми є 3 відео різних форматів: пояснювач, порівняння і «своя версія» найшвидшого відео кластера. Без AI це шаблони. З `--ai` ChatGPT або Claude переглядають кластери, об'єднують і перейменовують їх, а для кожного пишуть 3 відео зі сценарієм. Кількість кластерів задає `--clusters 5`.

Далі звіт показує ключові слова швидких відео, формат топу (частка Shorts, тривалість, чи є в назвах цифри та питання), години публікації та канали-лідери.

**«Що росте»**: кожен запуск зберігає знімок у `trends/out/history/`. Наступний запуск показує нові слова (NEW) і ті, що виросли на 30%+. Запускайте щодня, бажано в один час. Тоді ви побачите тренд на зльоті, а не на піку.

## Як отримати ключ YouTube (5 хвилин, безкоштовно)

1. https://console.cloud.google.com/ → створіть проєкт.
2. «APIs & Services» → «Library» → **YouTube Data API v3** → Enable.
3. «Credentials» → «Create credentials» → **API key**. Скопіюйте його в `YOUTUBE_API_KEY`.

Квота: 10 000 одиниць на добу. Кожна нішева фраза коштує 100 одиниць, решта майже безкоштовна. Запуск трьох ринків по 2 фрази ≈ 620 одиниць, тож на день вистачає ~15 таких запусків.

## Threads: як отримати токен і важливе обмеження

Threads має офіційний пошук постів за ключовими словами, але **поки Meta не схвалить ваш застосунок для дозволу `threads_keyword_search`, API шукає лише у ваших власних постах**. Інструмент це помітить і попередить. Схвалення (App Review) займає від кількох днів до кількох тижнів. Без токена розділ Threads просто порожній, решта звіту працює.

1. https://developers.facebook.com/apps → **Create app** → сценарій **Access the Threads API**.
2. У налаштуваннях застосунку додайте дозволи `threads_basic` і `threads_keyword_search`.
3. **Roles → Threads Testers**: додайте свій акаунт Threads і підтвердьте запрошення в застосунку Threads (Налаштування → Акаунт → Веб-сайт).
4. Отримайте токен користувача (User Token Generator у налаштуваннях Threads API) і вставте його як `THREADS_ACCESS_TOKEN`.
5. Щоб шукати публічні пости, подайте `threads_keyword_search` на **App Review**.

Ліміт: 2 200 пошуків на добу. Інструмент робить до 6 пошуків на ринок.

## Звіти в Telegram

1. Створіть бота в [@BotFather](https://t.me/BotFather) (`/newbot`) і скопіюйте токен.
2. Запустіть `TrendScout.command`. На питання `TELEGRAM_BOT_TOKEN` вставте токен. Скрипт попросить написати боту `/start` і сам знайде ваш чат.
3. Після кожного запуску бот надсилає: короткий підсумок по кожному ринку (Google, TikTok, що росте, топ відео), усі кластери з 3 відео, спільні тренди та «вже в США», а також повні HTML-звіти файлами.

**Щоденний автозапуск** (звіт сам приходить у Telegram щоранку):
```bash
bash trends/install_daily_mac.sh          # щодня о 09:00
bash trends/install_daily_mac.sh 7 30     # о 07:30
bash trends/install_daily_mac.sh --remove # вимкнути
```
Якщо Mac у цей час спить, звіт прийде, щойно він прокинеться. Не надсилати в Telegram окремий запуск: `--no-telegram`.

### Запити через бота

Боту можна писати запити, і він відповідає аналізом:

| Повідомлення | Що робить |
|---|---|
| `/trends` | Усі три ринки |
| `/trends de` | Один ринок (`ua`, `de`, `us`) |
| `/topic оренда Київ` | Аналіз теми в основному ринку |
| `/topic us rent prices` | Тема в конкретному ринку |
| будь-який текст | Те саме, що `/topic` |
| `/niche ua вартість життя; ціни` | Змінити постійні нішеві фрази ринку |
| `/market de` | Основний ринок для простого тексту |
| `/status` | Налаштування і які ключі підключено |

Увімкнути бота (працює у фоні й після перезавантаження):
```bash
bash trends/install_bot_mac.sh            # увімкнути
bash trends/install_bot_mac.sh --remove   # вимкнути
```
Бот відповідає, поки Mac увімкнений і не спить (у налаштуваннях Mac можна вимкнути сон при підключеному живленні). Відповідає лише вам: чужим людям він показує їхній chat_id, і ви можете додати його в `TELEGRAM_ALLOWED_CHATS` у `~/.trendscout`. Лог: `trends/out/bot.log`.

Токен бота зберігається лише у `~/.trendscout` на вашому Mac. Ніколи не додавайте його у файли репозиторію.

## Корисні опції

| Опція | Що робить |
|---|---|
| `--markets ua,us` | Лише вибрані ринки (`all` = усі з `markets.json`) |
| `--region PL --lang pl` | Довільна країна поза налаштованими ринками |
| `--days 3` | Лише найсвіжіше в ніші |
| `--shorts-only` | У ніші шукати лише короткі відео |
| `--category 24` | «Популярне» лише в категорії (24 Розваги, 22 Люди і блоги, 27 Освіта, 20 Ігри, 10 Музика) |
| `--tiktok-period 30` | TikTok за 30 днів замість 7 |
| `--tz Europe/Warsaw` | Часовий пояс для годин публікації |
| `--no-youtube` / `--no-google` / `--no-tiktok` / `--no-threads` | Вимкнути джерело |
| `--clusters 7` | Скільки кластерів трендів (по 3 відео в кожному) |
| `--ai-provider openai` / `claude` | Хто пише ідеї. За замовчуванням OpenAI, якщо є його ключ |
| `--openai-model gpt-5.4` | Інша модель OpenAI (за замовчуванням `gpt-5.4-mini`) |
| `--model claude-sonnet-5-5` | Інша модель Claude |

Ключ OpenAI створюється на https://platform.openai.com/api-keys. Підписка ChatGPT Plus його не включає: API оплачується окремо, з балансу на platform.openai.com. Один запуск на три ринки коштує копійки, але на балансі має бути хоча б $5.

## Обмеження

- **TikTok не має відкритого API трендів.** Інструмент читає публічні сторінки Creative Center. Якщо TikTok змінить сторінку або регіон не підтримується (для UA даних може не бути), розділ буде порожній. Для DE і US дані зазвичай є, а решта звіту працює як звичайно.
- YouTube прибрав вкладку «У тренді» з сайту. API-чарт `mostPopular` досі працює і є найближчим замінником.
- Google Trends RSS неофіційний. Якщо його вимкнуть, розділ буде порожнім.
- У хмарному середовищі Claude Code трендові сайти заблоковані, тож там працює лише `--demo`. Запускайте на своєму комп'ютері (потрібен лише Python 3.9+).
